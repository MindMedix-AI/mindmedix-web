# MindMedix Web

This repository contains the public web experience of MindMedix AI, including marketing properties and customer-facing web applications.

**One responsibility:** Public web experience (marketing, dashboard, hospital portal).

**Technology:** Next.js with TypeScript, React, Tailwind CSS, SQLite + Resend. GDPR-compliant, accessible.

**Engineering Principles:** Security-first, privacy-first, responsible AI, accessible, reliable, maintainable.

**Current Status:** Production-ready with CI/CD pipeline.

**Getting Involved:** Visit [MindMedix-AI GitHub](https://github.com/MindMedix-AI) for complete engineering organization and private repositories.

**About MindMedix AI**

Building predictive operational intelligence for European hospitals through responsible AI. Started 2024, based in Ancona, Italy.
