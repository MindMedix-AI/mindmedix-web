# Security Policy

MindMedix AI takes the security of our systems and our users' data seriously. As a healthcare AI company, we adhere to strict security and privacy standards.

## Supported Versions

Only the latest production release is supported with security updates.

## Reporting a Vulnerability

**Do not open a public GitHub issue.** Instead, report security vulnerabilities privately to:

**Email**: security@mindmedixai.health

Please include as much detail as possible:
- Type of vulnerability
- Steps to reproduce
- Affected versions
- Potential impact

You can expect:
- **Acknowledgement** within 48 hours
- **Status update** within 5 business days
- Coordinated disclosure timeline

## Responsible Disclosure

We ask researchers to:
- Share details before public disclosure
- Avoid accessing or modifying user data
- Respect privacy during testing

## Compliance

MindMedix AI follows:
- **GDPR** (General Data Protection Regulation)
- **EU AI Act** (Artificial Intelligence Act)
- **ISO 27001** readiness standards
- **OWASP** security best practices

## Scope

This policy applies to all repositories within the MindMedix-AI GitHub organization. For infrastructure-specific concerns, see `mindmedix-infrastructure`.
